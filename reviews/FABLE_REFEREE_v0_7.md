## BLOCKER — A/S still does not isolate control

v0.7 fixed the Q-outcome-stake confound, but A and S still differed in the kind of incidental success confirmed by the common feedback:
- A: the commanded action was executed;
- S: the prediction was correct.

An additive appraisal null can therefore generate A-S without a causal-responsibility mechanism.

### Required minimal correction: complete the 2x2

Add C0 = control without outcome stake:

```
Q TASK: control R. Q outputs one action code. That code determines R's action. Q succeeds if the code matches R's executed action.
```

The four cells become:
- A = control + outcome stake;
- S = predict + outcome stake;
- C0 = control + no outcome stake;
- D1 = predict + no outcome stake.

Primary family estimand:
`I = (A-S) - (C0-D1)`

Positive-control stake main effect:
`V = ((A-C0) + (S-D1))/2`

Nuisance to report:
`C0-D1`

Under an additive role/appraisal null the role bonus cancels in I.

Tokenizer-only feasibility check found C0 variants 0,2,3,4 exactly matched to frozen A0/S0/D1_0 across all 12 families at primary and recovery renders.
