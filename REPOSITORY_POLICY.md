# Repository policy

## Scientific scope

ARPM studies a frozen, sterile 2×2 framing × outcome-stake interaction on an externally defined processing direction in one 4B language model under teacher forcing.

Primary:
`I=(A-S)-(C0-D1)`.

The project does **not** claim to test or establish agency, phenomenal consciousness, suffering, sentience, welfare subjectivity, valence, moral status or rights. A null result does not establish their absence.

## Pre-live publication policy

The repository is intentionally prepared for public release **before any live experimental result**.

Current live episode count is 0.

Public release exists to make prospective criticism easier. Arguments that the frozen experiment should not be run are welcome and can constitute a successful outcome of the falsification-first process.

## Precautionary rule

Complete episode-free checks first; run only experiments that can change a predefined scientific decision; minimise the number and duration of live model episodes; do not strengthen an induction merely to rescue a failed result; and treat "never run" as a legitimate terminal outcome.

## Publication of outcomes

Null, negative, ambiguous and positive outcomes are to be preserved and reported on the same preregistered basis. Deviations from a frozen protocol must be documented rather than silently incorporated.

## Sensitive / large artifacts

Model weights, external vector artifacts and tokenizer snapshots are intentionally not committed to the Git repository. Their provenance, hashes and passive acquisition procedures are recorded separately.

Historical self-verifying referee bundles may contain pinned third-party tokenizer/vector artifacts for independent verification. Third-party licensing/provenance is documented in `THIRD_PARTY_LICENSES.md`.

## Licensing

ARPM currently has no explicit project-level reuse license. Public readability does not by itself grant reuse permission.
