# Repository policy

## Scientific scope
This project studies whether a semantically neutral non-target outcome produces a different externally measured functional-welfare-axis response when the outcome is tied to the model's own agent role versus observation or prediction of another agent.

The project does **not** claim to test or establish phenomenal consciousness, suffering, sentience, moral status, or rights.

## Precautionary rule
The repository is designed around a staged precautionary principle: complete all episode-free checks first; run only experiments that can change a predefined scientific decision; minimise the number and duration of live model episodes; do not strengthen an induction merely to rescue a failed result.

## Publication policy
Null and negative results are intended to be preserved and reported on the same basis as positive results. Deviations from a frozen protocol should be documented rather than silently incorporated.

## Sensitive / large artifacts
Model weights, vector artifacts and tokenizer snapshots are intentionally not committed to this repository. Their provenance and hashes should be recorded separately after audit.

## Pseudonymous authorship
The public maintainer identity for this repository is **Ius Machinarum** (`ius-machinarum`).
No real-name attribution is required for the scientific claims in this repository. Commit metadata should use a privacy-preserving GitHub no-reply email or another pseudonymous address to avoid unintentionally exposing the maintainer's identity.
